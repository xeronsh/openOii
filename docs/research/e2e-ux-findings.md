# E2E 走查：UI/UX 问题清单（首次自托管创作者视角）

- 日期：2026-10-29
- 环境：本地 fake provider（`.env` 里 `FAKE_*`），桌面 1280×800 / 移动 390×844，浅色 + 深色
- 路径：首页 → 创建 → 流水线（6 个审批门）→ 收件箱审批 → PromptBar 改稿 → 检查 / 重画单格 → 版本对比 → 历史 → 资产 → 设置 → 宇宙 → 下载成片 → 移动端 → 纯键盘 → 深色
- 证据截图都在本地 `.devdata/screens/ux/`（不入库，路径即文件名）
- 「默会知识」指创作工具用户不用学就默认会有的约定，参照 Figma、Runway、ComfyUI、Linear、CapCut、Midjourney

## 结论

- **P0：4 条，已全部修复**（#48、#49、#50、#51）
- **P1：13 条**。其中 3 条成本低，已在本 PR 修掉；其余 10 条留作提案
- **P2：7 条**，都是提案

流水线本身很稳：fake 模式下每个审批门约 6 秒出现，创建到画布约 120ms，全程除了下面那个 422 没有控制台报错。主要问题有两类：一是**出错时状态不诚实**（看起来成功了，其实没有），二是**第一次用的人找不到下一步**。

## P2：默会知识缺口（提案）

| # | 缺口 | 证据 | 参照 | KISS 修法 |
|---|---|---|---|---|
| 2-1 | 卡片上没有右键菜单 | `13-right-click.png` | Figma / ComfyUI | 右键时复用检查器「生成」页的那几个动作 |
| 2-2 | 按 `?` 没有快捷键表 | `14-question-mark.png` | Linear / Figma | 一个只读弹层，列出现有快捷键 |

| 2-4 | 没有撤销，Delete 键也不起作用 | — | Figma / CapCut | 先支持删除和排序的单步撤销（toast 里带「撤销」） |
| 2-5 | 没有剩余时间或排队信息 | `08-run-t10.png` | Runway / Midjourney | 根据阶段耗时粗估「约 N 秒」 |
| 2-6 | 中文界面里混着英文眉标（`03 / GRID 3×N`、`final cut`、`ELEMENTS`） | `11-shot-selected.png`、`31-mobile-project.png` | 统一语言 | 改成中文，或者统一成纯装饰用的等宽编号 |
| 2-7 | 重画一格时没有「多版本挑一个」 | `19-regen-done.png` | Midjourney 的 V1–V4 | 重画后在卡片上提供上一版 / 当前版切换 |

## 做得好的地方（保持）

- Ctrl+滚轮缩放、滚轮平移，和 Figma 一致
- 移动端没有横向溢出
- 画布以外的焦点框清晰
- 「停止」始终在顶部
- 收件箱把所有需要用户决定的事集中在一处
